**Search and scores (D6 implements the user's algorithm, with these initial deterministic parameters).** Extend the existing R9C functions. Offline discovery searches 2–5 actual traversed evidence edges, beam width 64 **globally per depth**, 16 eligible outgoing edges per expanded node, no repeated nodes, at most one weak contextual edge. Select outgoing edges by quality-sorted round-robin over relation types, stable ID tie-breaks. Never use a passage container as the sole bridge. Identity resolution chooses a verified occurrence/sense/lexeme anchor and records that choice; any subsequently traversed identity/form edge counts toward the hop limit. Existing R8 lemma summaries may supply projected edges only with the exact statement/occurrence witnesses retained; no fabricated shortcut edges or hidden multi-hop compression to satisfy the limit.

Initial edge weights: explicit identification/direct quotation 1.00; verified grammar 0.90; attested lexical/translation 0.75; validated form 0.70; structural parallel 0.45; curated cross-reference 0.40; contextual co-occurrence 0.15. Explicit interpretation/reference receives 1.00 only with explicit source evidence; possible allusion is candidate evidence capped at 0.40. Administrative identity links are verified mapping steps, never additional corroboration. Missing/unsupported transitions are ineligible, not assigned an invented weight. Path quality `Q = geometric_mean(weights) * 0.95^(hops-2)`. These are ranking weights, not probabilities or theological confidence.

For convergence, group support by underlying source annotation/claim and passage/edition-equivalence lineage, not record count. Duplicate exports, inverse edges, overlapping spans of the same assertion and two Greek editions do not count independently. Let `g` be the number of independent supporting groups; `C = min(1, log2(max(1,g))/3)`. Compute weighted feature rarity from `idf(f)=min(6, 1+ln((N+1)/(df(f)+1)))`, where N is the number of indexed clauses/scenes; distinctiveness `D=mean((idf-1)/5)` and relation diversity `T=min(1, distinct_nonadministrative_relation_types/4)`. Interest `I=clamp(0.45*bestQ + 0.30*C + 0.15*D + 0.10*T - penalties,0,1)`. Preserve book/structure/source-group breakdown; authorship is optional sourced metadata, never guessed from book titles. Initial hub penalty is `0.10 * mean(min(1, log1p(intermediate_degree)/log1p(max_graph_degree)))`; repeated-attestation penalty is `0.10 * duplicate_support_fraction`. Reject generic-only and unsupported paths outright. Report every component separately. These minor constants are initial tuning parameters; changes require measured recall/runtime evidence and a score-version bump, not new architecture.

Select up to 24 recommendations using MMR: `I - 0.35 * max_overlap_with_selected`. Overlap is the mean of Jaccard overlap of canonical edge IDs, evidence passage IDs and typed relationship-pattern signatures (empty/empty contributes zero). Keep alternate independent routes within a destination; rank/deduplicate paths before MMR over destinations. No synthetic mechanism quotas.
