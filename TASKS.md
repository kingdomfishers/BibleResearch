### N.3 Target architecture (the contract all tasks implement)

**Principles.** (1) Notes are a separate epistemic layer: `epistemic_layer:'user_note'` in every API output, never merged into evidence counts, never cited as source evidence. (2) One note ⇒ many anchors ⇒ optional typed connections between anchors of the same note. (3) Content = `body_md` (always) + ordered typed `note_blocks` from a registry (future map/timeline/3D = registry row, no migration). (4) SQL-first: tiers, scope matching, search, validation, writes live in PostgreSQL RPCs; TypeScript and MCP stay thin. (5) Explicit failure: write RPCs return `{ok:false,error:{code,message,field?}}`; they raise only on unexpected faults.

**Error codes:** `writes_disabled`, `validation_failed`, `not_found`, `version_conflict`, `rate_limited`, `forbidden`, `anchor_invalid`, `payload_too_large`, `not_available_in_single_user_mode`, `auth_required`, `block_type_not_enabled`.
