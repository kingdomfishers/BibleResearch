# BibleResearch

For biblical text research, use the bundled bible-research skill and connected
MCP tools. A substantial investigation can start with get_research_prompt and
the reader's subject; the default study_bible workflow routes the task. Simple
lookups can call the relevant data tool directly. Honor explicit completeness
and response-format requests. Never present a sampled occurrence list as full.
If new tools are missing, refresh MCP discovery rather than claiming they ran.
