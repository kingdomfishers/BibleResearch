## Implemented

- Dependency-free ESM with a TypeScript declaration, compatible with the existing scripts/corpus-worker.mjs runtime and TS imports. Global Needleman–Wunsch and local Smith–Waterman alignment (linear gap, weighted feature Jaccard; not affine yet).
- Medoid-first progressive multiple alignment, occurrence columns, peer-supported omissions, additions, substitutions, and explicit modifier additions. Surprisal is Laplace-smoothed, conditional on the inferred column; it is heuristic, not a p-value. Omission locations use neighboring attested events, not invented words.
- Exact repeated event n-grams (2–8), suppression of contained duplicate patterns; run on a lexical event stream for phrases and a clause event stream for structural sequences.
- Automatic segmentation proposals from repeated 1–3 event anchors, evaluating start/end splits and ranking by a compression proxy, coverage and template support. Unassigned leading/trailing text is retained as IDs, not interpreted as missing material. Not full MDL: the proxy is explicitly labeled.
- Contiguous reverse symmetry with 0–2 central events, distinct anchors and a forward-parallelism comparison. Candidates only, not proof of intentional chiasm. Gapped/noncontiguous and hierarchical structures are future extensions.
- Bounded passage-local processing (160 events for auto templates/chiasms, 256 for other operations, 32 units, at most 16 seed families).

## Evidence and integration

An event is {id, key, wordIds, features}. The caller must resolve every id to a source span in one edition and retain an event registry for output hydration. wordIds must be actual stable edition-scoped token IDs, not Strong's IDs or guessed positions. key is an original-language lemma identity (prefer lemma_key to Strong's) for a lexical stream, or a canonical predicate/role tuple for clause streams. features are typed namespaced evidence e.g. lemma:H..., role:subject=..., frame:..., modifier:degree=... derived from actual tokens or MACULA frames. The default key comparison is exact; avoid collapsing homographs. Shared features are not claims of historical etymology. Do not derive key equivalence from English glosses. Distinguish Aramaic, Hebrew, NT Greek, LXX and editions; run separate analyses.

1. Adapt the existing compact passage loader in scripts/corpus-relationships-rpc.mjs and the MACULA role frame sources used in src/relationships/symbolic-patterns.ts. Maintain separate lexical and clause streams; exact adjacent words must not be made adjacent by filtering intervening tokens. Resolve IDs to original words, verses, transliteration and English glosses. Include original spans in a deduplicated registry. Do not run full corpus scans in the browser.
2. Reuse src/relationships/wordplay-engine.ts (normalizeOriginalForm, compareOriginalForms, existing wordplay edges) for passage-local candidates and source spans; avoid a duplicate wordplay engine. Use existing motif-discovery.ts, evidence-synthesis.ts and r10-discovery.ts for corroboration, not as proof of local literary structure.
